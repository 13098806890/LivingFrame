# GIFBloom 小红书开发手记（09.09—09.15）

本组图片为 3:4 竖版 PNG，可按文件名顺序直接作为一篇小红书图文发布。固定结构是“产品/本期主题封面 + 4 张开发进度卡”，下次更新可沿用 `make_cards.swift` 的版式，替换卡片文案、日期和需要展示的素材。

## 本组内容

1. `01-cover.png`：GIFBloom 图标、产品用途和本期主题
2. `02-library.png`：素材多选、文件夹批量整理和安全删除
3. `03-editor.png`：画布纹理、缩略图预览与“剪影 / Cutout”术语一致性
4. `04-export.png`：剪影裁剪旋转、透明 GIF 规格与相册保存
5. `05-quality.png`：草稿/正式作品保存边界、帧率选项和定向回归

## 重新生成

在 macOS 上运行：

```sh
swift make_cards.swift background.png app-icon.png 输出目录
```

页面使用 AppKit / PingFang 字体将中文绘制到 PNG；底图和图标分别使用本目录内素材以及项目 `AppIcon-1024.png`。生成图片不包含测试照片，避免把私人相册素材带入公开内容。
