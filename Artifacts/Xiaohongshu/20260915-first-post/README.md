# GIFBloom 小红书首帖

本组为 4 张 3:4 竖版图（1080×1440）：封面、开发缘起、为什么自己做、最近进度。每张右下都保留了同一个低对比透明棋盘空位，方便后续叠放 GIFBloom 导出的表情包。

## 配文草稿

女儿出生以后，我手机里一下多了好多小视频。她那些小表情、小动作，我都想留着；有时候也想发给家人朋友看看，但又不太想直接把照片和视频发出去。

后来我想，要不把这些瞬间做成表情包？试了几个做 GIF 的软件，总觉得不太顺手，索性自己开发了一个，叫 GIFBloom。

现在可以选视频或 Live Photo，把人物做成剪影，再加点文字、贴纸，调一调时间，导出透明 GIF。

最近这几天，我在继续打磨素材整理、裁剪旋转、导出和草稿保存这些细节。第一次在小红书发开发记录，之后隔几天来更一次～
