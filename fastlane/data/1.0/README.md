# App Store Connect 1.0 baseline

This is the complete tracked baseline for the current editable `1.0` App Store version. The weekly, monthly, annual, and lifetime purchase definitions and localized fields mirror the current App Store Connect records. Price files preserve the current price points and customer prices, while per-product availability files record the selected territories and new-territory settings as of 2026-09-17.

The `null` and `NEEDS_*` values identify information that should not be sent to App Store Connect until the owner confirms it. They are part of the completeness record, not ready-to-upload values.
