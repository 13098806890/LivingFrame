# App Store Connect 1.0 baseline

This is the complete tracked baseline for the current editable `1.0` App Store version. Purchase definitions and localized purchase fields mirror the current App Store Connect records. Price files preserve the current price point and customer price for each configured territory as of 2026-09-17.

The `null` and `NEEDS_*` values identify information that should not be sent to App Store Connect until the owner confirms it. They are part of the completeness record, not ready-to-upload values.
