# AI sunglasses stickers

The 2D authored views and 3D model renders live under this shared source folder:

- `2d/` contains the artwork notes for the hand-drawn multi-view sticker.
- `3d/` contains the SceneKit model and its baked camera views.

Both sticker definitions appear in the same **AI Stickers** picker category. Each definition keeps its own rendering mode, and all runtime PNGs are bundled together under `GeneratedStickers/AI贴纸/`.
